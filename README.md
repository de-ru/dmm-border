# ボーダーナビ (Border Navigation & Calculator)

パチンコ機種のボーダー一覧検索、カスタム交換率・持ち玉比率のリアルタイム計算、機種詳細ページへのダイレクト遷移ができる自分用のWebツールです。  
ビルド不要の静的Web構成（HTML/CSS/JS）となっており、GitHub Pagesで即座に無料ホスティングできます。  
また、GitHub Actionsにより毎週日曜日に自動でデータ更新＆コミットが行われます。

---

## 🌟 主な機能

1. **ボーダー一覧 & インクリメンタル検索**
   - **全2,051機種** のパチンコボーダーデータベースを初期収録。
   - 機種名・メーカー・スペック（ミドル/ライトミドル/甘デジ/スマパチ/羽根モノ）による即時絞り込み。
   - お気に入り機種登録（ブラウザのローカルストレージに保存）。
   - ボーダー甘い順 / 辛い順 / 導入日順 / 50音順ソート。
   - カード表示とテーブル表示のワンタップ切り替え。
   - 大量データでも快適に動作するページング・段階的表示（60件ずつ表示＋もっと見る機能）。

2. **リアルタイム カスタム交換率 & 持ち玉比率計算**
   - 換金率プリセット（等価4.0円、28玉/3.57円、30玉/3.33円、33玉/3.03円、35玉/2.85円、40玉/2.50円）および自由入力。
   - 持ち玉比率スライダー（0%〜100%）。
   - 4円パチンコ / 1円パチンコのレート切り替え。
   - 設定条件に合わせた「合成ボーダー回転数」を全機種リアルタイムに再計算して大きく表示。

3. **クイック期待値シミュレータ & 詳細遷移**
   - カードの「期待値シミュ」ボタンから、実測のスタート回転数を入力するだけで、ボーダーとの差分（±回転）と台の優秀度を自動判定。
   - 「詳細・解析 ↗」ボタンから各機種の解析情報ページ（DMMぱちタウン等）へワンクリックで遷移。

4. **安全設計の自動更新 & 差分マージ (GitHub Actions)**
   - **運用方針**: ローカル環境で既存の全機種データベース（2,051件）を蓄積し、毎週日曜の自動更新では **1ページ目の新着台のみを取得して安全にマージ追加**。
   - 既存の過去機種データが消えることは絶対にありません。
   - 万が一外部アクセス制限等が発生した場合でも、既存データを100%保護して安全に終了します。

## 🚀 GitHub Pages での公開手順

1. **リポジトリのプッシュ**
   このプロジェクトを GitHub のご自身のリポジトリにプッシュします。

2. **GitHub Pages の有効化**
   - リポジトリの **Settings** タブを開きます。
   - 左側メニューの **Pages** を選択します。
   - **Build and deployment** の設定：
     - **Source**: `Deploy from a branch`
     - **Branch**: `main`（または `master`）
     - **Folder**: `/docs` を選択
   - **Save** をクリックします。
   - 数分後、発行されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）でアクセス可能になります。

3. **GitHub Actions の書き込み権限設定**
   GitHub Actions が自動更新した `data/borders.json` をコミット・プッシュできるように設定します。
   - リポジトリの **Settings** > **Actions** > **General** を開きます。
   - 下部の **Workflow permissions** で、**「Read and write permissions」** にチェックを入れて保存します。

## 🛠️ ローカルでのプレビュー

ビルド工程は一切不要です。ブラウザで `docs/index.html` を開くか、ローカルHTTPサーバーを起動して確認できます。

### Python の簡易サーバーを使う場合
```bash
python -m http.server 8000 --directory docs
```
ブラウザで `http://localhost:8000` を開きます。

## 📝 データの追加・編集方法

### 手動での機種データ追加
`data/borders.json` に以下の形式でオブジェクトを追加するだけで即座に反映されます。

```json
{
  "id": "my-machine-id",
  "name": "機種名",
  "maker": "メーカー名",
  "type": "ミドル (1/319.7)",
  "category": "P機",
  "release_date": "2024-12",
  "border_equal": 16.8,
  "borders": {
    "4.00": 16.8,
    "3.57": 17.8,
    "3.33": 18.4,
    "3.03": 19.3,
    "2.50": 21.2
  },
  "detail_url": "https://p-town.dmm.com/machines/...",
  "notes": "スペック備考や特記事項",
  "updated_at": "2026-11-22"
}
```

### 自動収集スクリプトのカスタマイズ
`scripts/update_borders.py` 内の `fetch_from_sources()` 関数に、スクレイピング対象サイトのURLやHTML解析ロジックを追加・カスタマイズできます。
